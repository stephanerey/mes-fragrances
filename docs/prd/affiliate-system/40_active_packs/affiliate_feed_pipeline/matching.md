# Matching Pack Notes

## Principle

Precision first. Bad matches create business and trust issues.

## Matching ladder

1. exact identifiers;
2. locked manual mapping;
3. deterministic normalized variant key;
4. guarded fuzzy matching;
5. candidate for review.

## Auto-match requirements

Auto-match is allowed only when:

- score threshold passes;
- brand is compatible;
- category is fragrance;
- volume is compatible when known;
- concentration is compatible when known;
- exclusion keywords do not indicate a set/body product/tester/refill unless explicitly supported.

## Human review

All ambiguous items must become candidates.

## Manual correction

Accepted review decisions should create locked mappings to prevent repeated fuzzy decisions.
